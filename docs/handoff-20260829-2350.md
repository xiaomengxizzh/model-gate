## 问题 1：SSE 流式中断后不切换上游（已由无上下文子智能体修复，待复核/提交/上线）

**现象**：客户端 zcode 对话中断，报错 `上游流式响应中断：断流续传用尽，结束，已重连 2 次仍失败`；日志显示请求被钉在主上游 jiyuan（UTC 15:00-15:10 的 7 个请求全 `provider=jiyuan`，`provider=opencodego` 0 次）。

**用户预期机制**：① 主上游失效 → 切备用上游（fallbacks）；② 模型所有上游失效 → 切目录下一模型；③ 主上游恢复 → 自动切回。

**子智能体独立诊断**（原始报告转述）：
1. 流式响应在"响应头 2xx"阶段即被 `markOk`，随后断流不算失败 → 熔断计数被间歇性成功反复清零 → "头 2xx + 流中断"永远攒不齐 maxFailures → 切备用/切下一模型永不触发
2. 断流只对同上游续传（2 次失败即报错），备用上游无机会接管
3. 回切探活是非流式 ping → "非流式通/流式断"的上游被误判恢复 → 切回后又立刻断流

**子智能体改动**（工作区未提交，4 文件 +43/-14）：
