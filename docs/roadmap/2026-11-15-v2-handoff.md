## 5. 关键机制与坑

1. **订阅承载（保留套餐）**：`src/codex/auth.js` 的 `/backend-api/codex` 只在 `providers.<id>.gatewaySubscription.enabled=true` 时允许（loopback + 官方 host）；`src/index.js` 的 `patchSubscriptionRequestBody()` 做请求整形（input→list、`store:false`、`stream:true`、删 `max_output_tokens`、删重放 reasoning）。凭据由 `src/codex/local-subscription.js` **只读**读取；刷新在桌面启动器（CAS + 0600 原子写）。
2. **第三方参数剔除**：`projectThirdPartyResponsesParams()` 只对非官方 Responses 目标剔除 `reasoning.context`/`text.verbosity`/`include:reasoning.encrypted_content`（真机 400 实测）。
3. **工具下发**：`buildCatalog()` 对第三方 Responses 路由默认 `shell_type=unified_exec`，绝不写 `use_responses_lite`/`tool_mode:code_mode_only`（后者会让 Codex 不下发 `exec_command`）。
4. **429 跨域回退（已修复）**：`forward.js` 的限流异常带 `MG_FB_RATE_LIMITED` 和 `status=429`。候选 `catch` 同时识别 typed code 和状态码，阻断跨授权域回退。旧失败和修复后的复核分别见 [R008/R009 记录](../evidence/aggregation-v2-r008-r009-2026-11-15.md)与[复核记录](../evidence/aggregation-v2-freeze-rerun-2026-11-15.md)。
5. **中断/resume**：中断终态唯一、工具不完成；但 `resume` **不保证**复用同一 child thread（冻结树两次都新建了子代理）。若产品要"同子恢复"，需要客户端侧方案，不能用网关代码硬造。
6. **R009 单实例多租户**：`src/` 内没有 tenancy 接线（`x-mg-scope`/`x-mg-tenant` 被忽略），`src/tenancy/*` 只有原语。要做需按 A4 的六步最小改法（配置 schema → per-scope key → `createScopeStore` → 管理面 403/404 → 日志 scopeId → 迁移）。
7. **compaction 触发条件**：真机上不一定按 `auto_compact_token_limit` 触发；小阈值（4k）会循环压缩，20k–32k 夹具在小会话里不触发。用长会话自然增长更可靠。
8. **不要自建压缩**：契约禁止网关侧 summarize/摘要缓存/历史裁剪；`history/export` 是所有者批准的迁移导出例外（边界见契约）。
9. **DSML**：如果 Codex 没下发 tools，模型会输出 `<|DSML| invoke …>` 文本；这不是网关翻译问题，先查 `tools` 是否为空。
