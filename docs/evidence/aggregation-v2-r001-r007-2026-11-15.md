| Web UI 展示三方差异 | **FAIL（UI bug）** | 截图 [30](2026-11-15-r001-r007/30-conflict-409.png)：弹窗显示「**服务端未返回三方差异**；未做任何写入」，与回执矛盾 |

**UI bug 根因（代码事实，本任务禁止改 `src/**`）**：

- `src/ui-next/js/views/aggregation.js:120` `describeThreeWay(conflict)` 读取 `conflict.detail.threeWay`；
- 但 `src/ui-next/js/api.js:5-13` 的 `ApiError` 把服务端 body 放在 `.data`，`beginDeactivate`（`aggregation.js:613`）直接把 `e` 传给 `showThreeWay(e, ctx)`；
- 所以即使服务端返回完整 `detail.threeWay`，UI 也判定为“未返回”。
- 建议修复（后续提交）：`showThreeWay(e.data || e, ctx)`，或让 `describeThreeWay` 兼容 `conflict.data.detail`；并补一条 UI 单测覆盖 409 展示。
