## 3. 分段执行与收据

### 段 1：官方直连控制组（证明基线可用）
- 命令：真实 Codex CLI，官方 provider，单条合成 prompt。
- 收据：版本、model、stream 是否成功、终态、耗时；**不含正文**。
- 失败即停：401/403/额度异常 → 归档并停止全部后续段。

### 段 2：Go 工具轮（证明第三方工具执行）
- 命令：真实 Codex CLI → ModelGate (`route=opencode-go/deepseek-v4.1-flash`) → 本地/合成工具（nonce 回显）。
- 收据：工具调用 nonce、tool loop 轮数、usage、429/断流处理、终态。
- 必须证明：请求目的地是本机 loopback 网关，网关以本服务 UA 与域派生会话标识发往 Go。

### 段 3：原生同会话（唯一能签 Q04 的形态）
- 必须同时满足：**同一父线程**、原生 CLI 自己派发、子代理记录（child id）、真实 Go 工具结果回传父线程、取消与恢复各一次。
- 明确不能用：模型切换、两独立终端、MCP 摘要、SIWC 自有客户端、双 mock。
- 收据：父/子 request 的不可逆引用、终态序列、取消/恢复各一条。

### 段 4：失败与恢复
- 429、401/403、上游断流、用户取消、会话恢复各一次；证明不自动换模型/账号/计费。
