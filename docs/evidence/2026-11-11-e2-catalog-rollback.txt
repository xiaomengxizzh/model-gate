目标：验证目录生成器的 v1 → v2 → 回滚 prev 全链，而不是只测纯函数。
环境：临时目录 + 合成 gateway 配置；官方基线来自 codex debug models 导出；不联网、不写正式配置。

## 说明

- 回滚语义是**内容回滚**：把上一版目录写回输出文件，并更新状态指针；不是只改指针。
- 生成器对未声明推理档位的第三方模型给出 `assumed_reasoning_levels` 警告（不阻断），
  这与 D2「能力字段要有来源与置信度」一致——assumed 属于最低置信度，发布前应显式声明。
- codex 校验仍然离线（debug models 加载本地文件），不产生任何上游请求。

## 边界

- 未做"回滚后运行中的 Codex 重新加载"验证（客户端重载属 E6/D5 范畴，NOT_RUN）。
