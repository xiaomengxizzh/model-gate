1. **官方登录投影不泄漏凭据**：`/api/status.official` 字段白名单恰为 `{credential,reason,authMode,level,source,checkedAt}`；黑箱断言 access/refresh token、account_id、email 均不出现（UI-02）。

### F-5 [P2｜未修复] Go 429/限流没有独立表达，被当成"连不上本地网关"

## 5. 修复建议（交 Lead / owner，A5 不改产品代码）

1. **F-2/F-3**：`homeStateOf` 在 `status==null` 或 `codex.detectionLevel!=='detected'` 时返回 `recoverable_error`/新增 `unknown` 态；`deriveCodex` 对"无 detect 数据"保持 `found:null`（或显式 `detected:false`）并给出"无法探测"，不要 `found:false` + `detectionLevel:'detected'`。
2. **F-4**：`buildStatus` 把探测失败（reason ∈ {`codex_home_unresolved`,`auth_file_unreadable`,`auth_file_too_large`}）映射为 `credential:'unknown'`；`deriveOfficial` 已支持 unknown 分支。
3. **F-5**：`classifyAggregationError` 增加 `rate_limited`（429 + retryAfter），投影输出"OpenCode Go 当前受限（约 N 秒后可重试）"，主 CTA 保持重试但不更新 Key。
4. **F-6**：probe 解码 JWT `exp`（与 `readSubscriptionCredential` 同源判断），过期返回 `credential:'missing', reason:'access_token_expired'`（或未知）；UI 已有对应文案。
5. **F-7**：给 `deriveProductStatus` 增加 `phase:'preview_pending'` 或由 A2 把 428 预览态传给投影；`homeStateOf` 增加分支并保证 `primary='确认配置变更'`。
6. **F-8**：`mode==='unknown'` 返回 `recoverable_error`/专用未知态，不返回 `ready_to_enable`。
7. **F-9**：`restartNeeded = restart && restart.needed === true ? true : restart && restart.needed === false ? false : null`。
